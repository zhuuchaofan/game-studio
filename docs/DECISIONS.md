## 2026-11-24 — 推送路径走 Muse GitHub 连接器，不走 shell gh
- **决策**：AGY 在 shell 本地写代码，协调员经 Muse GitHub 连接器（MCP）`push_files` 快照推送到 `feature/m0-scaffold` 分支，再开 PR、合 main。
- **理由**：shell 里 `gh` 未登录、无 token；连接器已验证连通（账号 zhuuchaofan，仓库可读）；快照推送满足纯文本脚手架的推送需求。

## 2026-11-24 — AGY 调用须加 --dangerously-skip-permissions
- **决策**：AGY 以 print 模式运行时附加 `--dangerously-skip-permissions`。
- **理由**：实测：不加该参数时 print 模式无法提示授权，`read_file` 权限被自动拒绝，任务 9 秒即失败。加参数后任务正常进行。
- **风险与约束**：该参数会放行 AGY 的全部工具调用；缓解措施是任务书明确红线（不提交、不推送、不碰 GitHub、不写凭据、不联网收费服务）+ 协调员事后审查 AGY 的实际操作记录。长期应改为在 settings.json 里配最小权限 allow-rule（待 M0 后评估）。
- **影响**：M0 之后每次 AGY 调用都须带该参数，直到权限配置方案落地。

## 2026-11-24 — Vite base 用 './' 相对路径，不写死子路径
- **决策**：`vite.config.ts` 加 `base: './'`；禁止写死 `'/game-studio/'`。
- **理由**：试玩页在 Pages 子路径下全黑，查实是默认 `base: '/'` 使 `dist/index.html` 引用
  `/assets/...` 绝对路径，在 `/game-studio/` 下 404；相对路径使构建产物在任意子路径下都能加载，
  换托管路径不用改代码。
- **影响**：`dist` 引用全部相对化；本地 `vite preview` 与根路径部署不受影响。

## 2026-11-24 — 回归测试必须把 dist 挂在子路径下跑
- **决策**：新增 `tests/e2e/subpath.spec.ts`：测试内自启静态服务器把 `dist` 挂在
  `/game-studio/` 下，断言画布渲染出来且无失败请求；该测试必须能在旧构建上失败、新构建上通过。

- **影响**：CI 每次都跑该测试；以后改 base 或部署路径，测试先报警。

## 2026-11-24 — 机制卡 1 收当口碑规则改为成交结算且自洽
- **决策**：口碑只在成交时结算（低价成交 −1、平价 +0、高价 +1），任意档位被拒一律 +0；报价三档（50%/100%/150%）与接受率（30%/80%/100%）保持不变。
- **理由**：原草稿数值行写“−1（低价被拒时不扣，低价接受时 +0）”自相矛盾，导致低价没有口碑代价。
- **影响**：低价形成“高利润 + 掉口碑”的真实取舍，与高价（亏钱 + 涨口碑）、平价（中庸）构成三难选择，原型试玩重点验证玩家是否真的纠结。

## 2026-11-24 — 引入 mulberry32 种子随机数并支持 URL 参数 `?seed=`
- **决策**：新增 `src/utils/rng.ts` 实现 `mulberry32` 确定性伪随机数生成器；默认从 URL 查询参数 `?seed=` 读取种子，缺省时回退到 `Date.now()`。
- **理由**：收当接受率（低价 30% / 平价 80%）包含概率分支，固定种子使 Playwright E2E 能稳定覆盖接受与拒绝两条路径，避免测试抖动。
- **影响**：正常玩家不传 `?seed=` 时每次体验仍随机；测试与复现 bug 时可通过 `?seed=<n>` 精确重现随机序列。
