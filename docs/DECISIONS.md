# 决策记录（草稿 · M0 试点，试点结束后随代码一同进仓库）

> 格式：日期 — 决策 — 理由 — 影响。草稿须制作人审阅。

## 2026-11-24 — 方向定为《当铺纸牌》
- **决策**：第一款游戏做《当铺纸牌》（卡牌构筑 Roguelite + 轻经营）。
- **理由**：制作人 13:08 选定；P0 评估中卡牌构筑类型评分第 1（3.49），市场吸引力最高。
- **影响**：分辨率按概念文档定为 320×180；原型范围按 04 号文档第 11 项（20 张牌、2 种心魔、3 回合）。

## 2026-11-24 — 分辨率定为 320×180（16:9）
- **决策**：原生分辨率 320×180，不用 256×240。
- **理由**：概念文档第 8 项已定；牌桌是横屏的最佳形态。
- **影响**：全项目统一，不中途换；缩放只用整数倍。

## 2026-11-24 — 推送路径走 Muse GitHub 连接器，不走 shell gh
- **决策**：AGY 在 shell 本地写代码，协调员经 Muse GitHub 连接器（MCP）`push_files` 快照推送到 `feature/m0-scaffold` 分支，再开 PR、合 main。
- **理由**：shell 里 `gh` 未登录、无 token；连接器已验证连通（账号 zhuuchaofan，仓库可读）；快照推送满足纯文本脚手架的推送需求。
- **影响**：推送不经过本地 git 历史（无本地提交记录）；删除、二进制文件需另走 `delete_file` / `create_or_update_file` 单独处理；后续每次推送都要按 snapshot-push 规范做同步记录。

## 2026-11-24 — AGY 调用须加 --dangerously-skip-permissions
- **决策**：AGY 以 print 模式运行时附加 `--dangerously-skip-permissions`。
- **理由**：实测：不加该参数时 print 模式无法提示授权，`read_file` 权限被自动拒绝，任务 9 秒即失败。加参数后任务正常进行。
- **风险与约束**：该参数会放行 AGY 的全部工具调用；缓解措施是任务书明确红线（不提交、不推送、不碰 GitHub、不写凭据、不联网收费服务）+ 协调员事后审查 AGY 的实际操作记录。长期应改为在 settings.json 里配最小权限 allow-rule（待 M0 后评估）。
- **影响**：M0 之后每次 AGY 调用都须带该参数，直到权限配置方案落地。

## 2026-11-24 — 16 色主调色板草案方向
- **决策**：当铺暖黄 + 牌局深蓝的冷暖对比；16 色（暖 8 + 冷 5 + 点缀 3），见 `docs/ART_STYLE.md` 草稿。
- **理由**：概念文档第 8 项已定方向；白天/夜里同一间铺子两套配色是本作最直观的视觉识别。
- **影响**：待制作人确认后定稿；原型美术按此出牌面与场景。

## 2026-11-24 — 技术栈精确锁定
- **决策**：Phaser `3.90.0`（精确）、TypeScript `5.9.x`、Vite `8.3.8`、Vitest、Playwright。
- **理由**：P0 05 号文档结论；npm 上 `phaser` 的 latest 标签已指向 4.2.1，`^` 会装错；TS 7.0.2 刚出，求稳用 5.9.x。
- **影响**：`package.json` 必须写死版本号；升级须另行决策。
